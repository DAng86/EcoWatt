# EcoWatt

## Overview

EcoWatt is a Flutter-based household energy monitoring application developed as part of an academic project.

The application provides monitoring and analysis of electricity consumption across four household circuits and includes intelligent alerts, electricity cost estimation and energy-saving recommendations.

## Main Features

- Four-circuit household energy monitoring
- Real-time dashboard visualisation
- Historical energy consumption analysis
- SQLite database storage
- Intelligent alerts and recommendations
- Electricity cost estimation based on Mauritian CEB tariffs
- AIoT-inspired monitoring concepts
- ESP32 and SCT-013 prototype hardware implementation

## Technologies Used

- Flutter
- Dart
- SQLite
- ESP32
- SCT-013 Current Sensor
- MQTT Concepts
- Android Studio
- Visual Studio Code
